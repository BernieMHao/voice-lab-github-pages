## Seven additional model options

- **Kokoro 82M v1.0** — [hexgrad/Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), Apache-2.0. Uses the pinned ONNX Community conversion `onnx-community/Kokoro-82M-v1.0-ONNX@1939ad2a8e416c0acfeecc08a694d14ef25f2231`, INT8 graph and seven original voice matrices. English phonemization is adapted from `hexgrad/kokoro`'s JavaScript implementation; license retained at `vendor/kokoro/LICENSE`.
- **Kitten Nano / Micro / Mini 0.8** — [KittenML/KittenTTS](https://github.com/KittenML/KittenTTS), Apache-2.0. Nano uses `KittenML/kitten-tts-nano-0.8-int8@84781d74e29ee25217551556398b42f80593a813`, Micro uses `KittenML/kitten-tts-micro-0.8@1ccf72b2c2048fd17efac7de2fab32d10e225084`, and Mini uses `KittenML/kitten-tts-mini-0.8@c02725660cea441db4c383af69f1f26f5cd00947`. Original voice NPZ files and ONNX weights retained. Voice matrices are losslessly unpacked to float32 binary. Reference implementation and license retained in `vendor/kitten/`.
- **Piper Lessac Medium** — [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices), revision `5041a7a49ae5b3a0f30e6837769eb03fdbb231bd`, `en/en_US/lessac/medium/en_US-lessac-medium.onnx`. This integration runs the ONNX graph directly and does not bundle the Piper Python/C++ engine. Its voice-specific model card is retained at `public/support/models/piper/MODEL_CARD`, including the Lessac Blizzard 2013 dataset license link. Voice-specific terms apply separately from runtime code licenses.
- **Supertonic 3** — [supertone-oss-archive/supertonic-3](https://huggingface.co/supertone-oss-archive/supertonic-3), revision `aafc6e32416a594460b32413efc49d7fe4ce6d46`, **BigScience Open RAIL-M** model-weight license; retained as `public/support/models/supertonic/LICENSE`. Four original ONNX graphs and ten voice styles are unchanged. JavaScript helper adapted from the [archived official implementation](https://github.com/supertone-oss-archive/supertonic), **MIT** code license retained in `vendor/supertonic/`. Local changes force WASM-only imports and CPU session configuration.
- **Phonon 31M English** — [Gradium](https://huggingface.co/gradium/phonon-31m-en), revision `92741c5b07d085ff840e26fea8ce43110b87852f`, Apache-2.0. Uses original Q8 GGUF weights, tokenizer, config and default voice. No weight modification; uses the CPU-only xn-ptts runtime described above. Gradium's 31M parameter count excludes the audio tokenizer.
- **Phonemizer.js 1.2.1** — [Xenova](https://github.com/xenova/phonemizer.js), Apache-2.0 JavaScript wrapper (license retained in `vendor/phonemizer/LICENSE`), with embedded [eSpeak NG](https://github.com/espeak-ng/espeak-ng) WASM/data under its GPL-3.0 license. The original bundled file is retained at `public/phonemizer/phonemizer.js`. It is served locally; no phonemization API is called. Source and build instructions are available from those upstream projects.

Pinned download metadata and packaging are in `public/catalog.json` and `scripts/package-assets.py`. Original per-model cards are retained alongside each model in `public/support/models/`.

## Chinese model additions

- **Matcha icefall zh-baker** — [official model documentation](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese/matcha-icefall-zh-baker.html), trained with [icefall](https://github.com/k2-fsa/icefall/tree/master/egs/baker_zh/TTS). Original three-step ONNX acoustic graph, lexicon, jieba dictionary, FST normalization rules and Vocos 22 kHz vocoder. The original README is retained at `public/support/models/matcha/README.md` and states that the DataBaker dataset is for **non-commercial use only**. No model-weight modification.
- **ZipVoice-Distill** — [k2-fsa/ZipVoice](https://github.com/k2-fsa/ZipVoice), Apache-2.0; [official sherpa integration](https://k2-fsa.github.io/sherpa/onnx/tts/zipvoice.html). Original `sherpa-onnx-zipvoice-distill-int8-zh-en-emilia` encoder/decoder, lexicon, eSpeak data and Vocos 24 kHz. The default voice uses the official archive's `test_wavs/news-female.wav` and matching transcript from `prompt.txt`; original files are retained. No user-recording cloning interface is exposed.
- **sherpa-onnx** — [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), Apache-2.0. WASM and original JS API/runtime pinned to [official ZipVoice browser space](https://huggingface.co/spaces/k2-fsa/web-assembly-zh-en-tts-zipvoice/tree/a118980aaa8d985d10e57425c1fdc2301c05f4cc). CPU-only, SIMD, single-threaded binary; no GPU provider. Upstream files retained at `public/sherpa/upstream-*.js`, license at `public/licenses/sherpa-Apache-2.0.txt`; C++ entry/build references in `vendor/sherpa/`. Local changes remove automatic `.data` preloading, load only selected assets, expose Matcha `dictDir`, and run the engine in a terminable worker. Embedded eSpeak NG/data retains its GPL-3.0 license as above. Source/build instructions are in the upstream sherpa repository.
- **Qwen3-TTS 0.6B CustomVoice** — [Qwen model](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice), Apache-2.0, original config/tokenizer revision `85e237c12c027371202489a0ec509ded67b5e4b5`. INT4 graphs and reference `inference.py` from [ONNX Community conversion](https://huggingface.co/onnx-community/Qwen3-TTS-12Hz-0.6B-CustomVoice), revision `18b0bf898d211718bc33082fadc36a448e0cbc0c`. No local weight modification. `src/qwen-engine.js` adapts its non-streaming CustomVoice prefill, cached AR loop, residual-code sampling and fixed-frame decoding to JavaScript, forced two-thread CPU WASM. Source retained at `vendor/qwen/inference.py`. Model card retained in `public/support/models/qwen/README.md`.
- **OpenCC.js 1.0.5** — [nk2028/opencc-js](https://github.com/nk2028/opencc-js), MIT. Traditional-to-simplified conversion in the browser, only for the Matcha/ZipVoice dictionary frontends. License retained in `public/licenses/opencc-js-MIT.txt`.

Asset download metadata is in `public/catalog.json`; static file packaging is in `scripts/package-assets.py`.

## Pages packaging additions

- **coi-serviceworker** — [gzuidhof/coi-serviceworker](https://github.com/gzuidhof/coi-serviceworker), MIT. Response-header technique adapted in `public/sw.js`; license retained in `public/licenses/coi-serviceworker-MIT.txt`. No external running service.
- **@noble/hashes 1.8.0** — [paulmillr/noble-hashes](https://github.com/paulmillr/noble-hashes/tree/1.8.0), MIT. Incremental SHA-256 validation during model download. License retained in `public/licenses/noble-hashes-MIT.txt`.

Catalog SHA-256 hashes and fixed HF revisions identify the exact model artifacts. Files stored in the browser at virtual `/models/` URLs are served from its Cache Storage, not from an inference server. Some large Matcha/ZipVoice assets are split losslessly into 48 MiB static pieces to meet GitHub file limits. The full original file hash is checked after joining.
